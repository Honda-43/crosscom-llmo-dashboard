## 結論

**1. 旧事業の記述は例外ではなく常態である。** E-1回答 83件中 **80件(96%)** が
「メール配信 / メールマーケティング / マーケティングオートメーション」のいずれかを含む。
claude は **41日中41日**(100%)。単発の事故ではない。

**2. 主犯は自社サイトではなく、第三者の企業ディレクトリである。**
claude は旧事業を語った41日すべてで `cross-com.jp/about/` を引用しているが、
**`/about/` は既に現行事業(Agentforce / Agentic CRM)へ更新済み**である。
一方で旧事業の自社URLを引用したのは **41日中6日だけ**。
毎日引用されているのは AUBA(37日)・イプロス(33日)・PR TIMES(27日)といった
外部プロフィールで、ここに旧事業の記述が残っている。

**3. LLMが再生しているのは `/about/` の「旧版」の文である。** 決定的な証拠として、
文の前半が現行ページと完全一致し、後半だけが旧事業に置き換わっている(§3-1参照)。

**4. 副次的な発見として、R-P7の検知が実態に対して極端に少ない。**
本文ベースでは96%の回答が旧事業に言及しているのに、
`negative_or_outdated=TRUE` が立ったのは直近7日で1件(8/12)のみ。
**抽出段階(§4)で見逃されている**可能性が高い(§5参照)。

## 3. 本文の旧事業言及と引用URLの対応

### 3-1 最重要 — `/about/` の「旧版」が再生されている

| | 文面 |
|---|---|
| **LLM出力**(8件で一致) | 利益創出を目的とした全体最適のマーケティング活動を普及させるため、2023年5月にクロスコムを創業し、現在はBtoB領域に特化して、**中小企業のMAやメールマーケティング、マーケティング戦略コンサルティング**を支援しています |
| **現在の `/about/`**(実地確認) | 利益創出を目的とした全体最適のマーケティング活動を普及させるため、2023年5月にクロスコムを創業。現在はBtoB領域に特化して、**Agentforceの導入・定着支援と、Agentic CRMの設計支援**を展開。 |

**前半は一字一句同じで、後半の事業内容だけが旧版のまま。**
つまりモデルは「更新後の `/about/` を引用しながら、更新前の同じ文を出力している」。
出所は (a) 旧版を転写した第三者ページ、(b) 検索インデックス/キャッシュの残存、のいずれか。

### 3-2 定型化したサービス列挙

第三者プロフィールの転写と見られる4項目セットが繰り返し出現する。

```
BtoB MA導入・運用支援 / BtoBマーケティング戦略コンサルティング支援 /
BtoBコンテンツ企画・制作代行支援 / BtoBメールマーケティング代行支援
```

| 表現 | 出現 | 初出 | 最新 |
|---|---|---|---|
| BtoB MA導入 | 62件 | 2026-07-08 | 2026-08-17 |
| BtoBマーケティング戦略コンサルティング | 39件 | 2026-07-11 | 2026-08-17 |
| BtoBコンテンツ企画 | 35件 | 2026-07-11 | 2026-08-17 |
| BtoBメールマーケティング代行 | 28件 | 2026-07-11 | 2026-08-17 |
| 中小企業のMA | 33件 | 2026-07-08 | 2026-08-16 |

`主要事業 · BtoB MA導入・運用支援 · BtoB マーケティング戦略コンサルティング支援 · …`
のように**中黒区切りのリスト形式**で現れる回答があり、ディレクトリサイトの
項目表示をそのまま写した形跡がある。

### 3-3 本文と引用URLの対応の限界

claude E-1 41日のうち:

| | 日数 |
|---|---|
| 本文で旧事業を語った | **41 / 41** |
| 旧事業の**自社**URLを引用した | 6 / 41(7/8, 7/9, 7/17, 7/19, 7/20, 8/9) |
| `/about/` を引用した | 41 / 41 |
| **旧事業を語ったが旧事業URLは引用していない** | **35 / 41** |

回答本文にインライン引用が無く(旧事業言及の近傍に現れた本文中URLは
`https://cross-com.jp/` の3件のみ)、**文と出典の1対1対応は本文からは取れない。**
上記は「同一回答内に共起したURL」までが限界である。

ただし 3-1 の文面一致と、外部ソースの実地確認(§4)から、
**旧事業の記述は自社の旧ページよりも外部プロフィール由来である可能性が高い。**

## 5. 副次的な発見 — R-P7が実態を捉えていない

| | 件数 |
|---|---|
| 本文に旧事業キーワードを含むE-1回答(全期間) | 80 / 83 |
| `negative_or_outdated=TRUE` と判定された件数(直近7日) | **1**(2026-08-12 claude) |

直近7日は claude の7日すべてで旧事業に言及しているにもかかわらず、
フラグが立ったのは1日だけ。**§4の抽出段階で見逃されている。**

R-P7 は `negative_or_outdated` に完全に依存しているため、
このままでは「ネガティブ検知は週1件」という実態より軽い認識になる。
§4の抽出スキーマは変更禁止のため本調査では手を入れていないが、
**抽出プロンプトの判定基準の見直しは別途検討が必要**。

## 7. 本調査の制約

- **`negative_or_outdated` の全期間データは参照していない。** この値は抽出後の
  `llm_observations`(Sheets)にのみ存在し、`data/raw` には無い。本レポートの
  「旧事業に言及」は**回答本文のキーワード照合**による判定で、
  `negative_or_outdated=TRUE` の件数は `data/reports/2026-08-17.json`(直近7日)のみ。
- **gemini の引用元は追跡不能。** 全372件が grounding リダイレクトのため、
  §2-2 の分析は claude のみが対象。gemini 側にも同様の外部ソース由来の
  旧事業記述がある可能性は否定できない。
- **AUBA と PR TIMES は未確認。** JavaScript描画のため自動取得できなかった。
  引用回数1位・3位であり、**この2件の確認が本調査の最大の残件**。
- 「本文の文 ↔ 引用URL」の厳密な対応は取れない。回答にインライン引用が無いため、
  同一回答内での共起までが限界である。
- 外部サイトの内容は 2026-08-17 時点のもの。
